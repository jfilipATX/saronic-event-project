# Brand fonts

Free, openly licensed originals of the brand faces used by the P2-4 visual
composer (`app/features/visuals.py` picks these up by filename at render
time; DejaVu remains the last-resort fallback).

| File | Family | Source | License |
|------|--------|--------|---------|
| `ArchivoExpanded-Bold.ttf` | Archivo Expanded | github.com/Omnibus-Type/Archivo | SIL OFL 1.1 |
| `Archivo-Bold.ttf` | Archivo | github.com/Omnibus-Type/Archivo | SIL OFL 1.1 |
| `Inter-Regular.ttf` | Inter | github.com/rsms/inter (v4.1) | SIL OFL 1.1 |

All three are under the SIL Open Font License 1.1 — free for commercial use,
embedding, and redistribution. Full license texts at the source repositories.
